# Financial Advisor AI

An AI-powered financial advisor built with phidata that provides financial insights and analysis.

## Features

- Stock price information
- Analyst recommendations
- Company information
- Latest financial news

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   python playground.py
   ```

## Agents

- **Finance Agent**: Provides financial data and analysis using YFinance tools
- **Web Agent**: Searches the web for additional information using DuckDuckGo
```

File: requirements.txt
```
phidata
yfinance
duckduckgo-search
groq
```
